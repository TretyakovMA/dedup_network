# Traffic Deduplication IP-Core

IP-ядро системы сбора и дедупликации потоковых 32-битных данных «на лету» (On-the-fly) с узкими 8-битными каналами передачи.

---

## 🚧 Статус готовности (Status)

Ничего не готово, уходите

## 📁 Структура репозитория

```text
.
├── rtl/               # Исходный RTL-код на SystemVerilog
│   ├── pkgs/          # Пакеты констант и типов
│   ├── common/        # Общие модули (FIFO, CRC, Hash, BRAM)
│   ├── interfaces/    # Основные интерефейсы (SPI, AXIS)
│   ├── transmitter/   # Модули передатчиков
│   └── receiver/      # Модули приемника
├── rdl/               # Описание регистров на SystemRDL
├── dbg/               # Тестбенчи, UVM-окружения и скрипты симуляции
└── docs/              # Спецификация IP-ядра и архитектурные диаграммы

```

---

## 🚀 Быстрый старт (Quick Start)

### 1. Генерация кода из SystemRDL

Для генерации RTL-кода регистров выполните:

```bash
cd rdl
make rtl  # Подробности см. в rdl/README.md

```

### 2. Запуск симуляции

Подробные инструкции по запуску UVM и юнит-тестов находятся в [`dbg/README.md`](dbg/README.md).
Пример запуска теста для передатчика:

```bash
cd dbg/dedup_tx_top/run
make clean all

```
