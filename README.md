# Traffic Deduplication IP-Core

IP-ядро системы сбора и дедупликации потоковых 32-битных данных «на лету» (On-the-fly) с узкими 8-битными каналами передачи.

## 🛠 Ключевые характеристики

* **Экономия пинов:** Сокращение межчиповой шины с 32 до 8 бит (75%).
* **Алгоритмы сжатия:** TinyLFU + CU-CMS, Segmental LRU (2Q), Clock/CAR, Pure LFU.
* **Защита данных:** Блочный контроль CRC-8, Fast-Path аппаратная изоляция ошибок.
* **Интерфейсы:** AXI-Stream (данные), APB (конфигурация), iolink (конфигурация и MSI).

## 🚀 Быстрый старт (Quick Start)

### 1. Генерация регистров CSR из SystemRDL

Для генерации RTL-кода регистров из папки `rdl/` выполните:

```bash
make rdl_gen  # Подробности см. в rdl/README.md

```

### 2. Запуск симуляции

Подробные инструкции по запуску UVM и юнит-тестов находятся в [`dbg/README.md`](dbg/README.md).
Пример запуска юнит-теста для блока CRC:

```bash
cd dbg/common/crc && make

```
