# axis_input_fifo

## Назначение

Принимает слова через AXI-Stream и передаёт их контроллеру через синхронный FIFO с чтением головного слова до `pop` (First-Word Fall-Through, FWFT).

## Порты

### Параметры

`WIDTH=32` задаёт ширину слова. `DEPTH=16` задаёт число элементов и должен быть степенью двойки не меньше 2.

| Порт | Направление | Ширина или тип | Назначение |
| --- | --- | --- | --- |
| `clk`, `rst_n` | Вход | По 1 | Общий такт и активный низкий reset FIFO. |
| `tdata` | Вход | WIDTH | Слово источника. |
| `tvalid` | Вход | 1 | Источник удерживает tdata действительным. |
| `tready` | Выход | 1 | Возможен приём слова, равно !full. |
| `r_en` | Вход | 1 | Pop от controller. |
| `r_data` | Выход | WIDTH | Головное слово для захвата controller. |
| `empty`, `full` | Выход | По 1 | Статусы FIFO. |

## Логика работы

### Запись с AXI-Stream

Слово записывается на фронте `clk` при `rst_n && tvalid && tready`. Внутренний `fifo` получает `w_en=tvalid` и запрещает запись при `full=1`, поэтому `tready = !full`. Пока `tvalid=1` и `tready=0`, источник удерживает слово и `tvalid`. На полном FIFO одновременный `pop` освобождает место для следующего фронта.

### Чтение контроллером

При `empty=0` на `r_data` находится головное слово. Контроллер выставляет `r_en` и захватывает это слово на одном фронте `clk`. `TX_EN` разрешает контроллеру извлечение. Приём со стороны AXI-Stream продолжается до заполнения FIFO.

### Сброс и границы пакетов

Сброс очищает указатели внутреннего `fifo`. В сбросе `tready` может быть равен 1, поскольку зависит от `full`. Статистика передатчика учитывает handshake только при `rst_n=1`. `tdl_tx_top` передаёт в FIFO данные, `tvalid` и `tready`. Каждый принятый элемент обрабатывается как отдельное слово, поэтому `s_axis_tlast` в FIFO не хранится.
