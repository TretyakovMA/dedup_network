# tdl_tx_pkg

## Назначение

Задаёт общие для передатчика значения `frame_t`, `policy_algo_t`, формат `policy_cfg_t` и длительность программной выдержки TinyLFU.

## Интерфейс пакета

### Тип кадра

| Код `frame_t` | Тип | Заголовок SDR | Байты после заголовка |
| --- | --- | --- | --- |
| `2'b00` | `FRAME_RAW` | `8'hA1` | Четыре байта слова, старший первым. |
| `2'b01` | `FRAME_KEY` | `8'hB2` | Один байт ключа. |
| `2'b10` | `FRAME_SYNC` | `8'hC3` | Один байт ключа, затем четыре байта слова. |
| `2'b11` | Зарезервирован | — | Недопустимый базовый дескриптор. |

### Код алгоритма

| Код `ALGO_SEL` | Алгоритм |
| --- | --- |
| `2'b00` | `POLICY_TINYLFU` |
| `2'b01` | `POLICY_SLRU` |
| `2'b10` | `POLICY_CLOCK` |
| `2'b11` | `POLICY_LFU` |

### Снимок конфигурации

`policy_cfg_t` — упакованная структура из 32 битов. CSR-мост формирует поля, контроллер сохраняет их при извлечении слова, фасад декодирует поля для выбранной политики.

| Биты `policy_cfg` | Поле |
| --- | --- |
| `[1:0]` | `ALGO_SEL` |
| `[2]` | `CU_DISABLE` |
| `[3]` | `AGING_DISABLE` |
| `[4]` | `BF_EN` |
| `[7:5]` | 0 |
| `[15:8]` | `N_prob` |
| `[31:16]` | `AGING_PERIOD` |

### Константа обслуживания

`TINYLFU_IDLE_WAIT_CYCLES = 518` задаёт число периодов `clk`, которое ПО выдерживает от завершения чтения `STATUS_REG` с признаками пустого FIFO и простоя контроллера перед изменением настроек TinyLFU.

## Логика работы

Контроллер, очередь кадров и сериализатор передают дескриптор отдельными полями `type[1:0]`, `key[7:0]` и `data[31:0]` по `valid/ready`. Контроллер расширяет ключ словаря до восьми бит нулями. Для RAW ключ равен нулю, для KEY поле данных не выходит на провод. Заголовки SDR `A1`, `B2` и `C3` формирует сериализатор по `frame_t`.

`policy_cfg_t` и `frame_t` относятся к разным интерфейсам. `BYPASS_EN` поступает в контроллер отдельно от `policy_cfg_t`. Коды состояния контроллера определены в его RTL и передаются в CSR через `state_code`.
