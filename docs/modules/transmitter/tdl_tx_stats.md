# tdl_tx_stats

## Назначение

Считает принятые слова, завершённые кадры и отказы фильтра Блума. Формирует источники прерываний и передаёт значения в CSR-мост.

## Порты

| Порт | Направление | Ширина или тип | Назначение |
| --- | --- | --- | --- |
| `clk`, `rst_n` | Вход | По 1 | Такт и активный низкий reset. |
| `axis_accept` | Вход | 1 | rst_n && s_axis_tvalid && s_axis_tready. |
| `frame_done` | Вход | 1 | Завершение кадра serializer. |
| `frame_done_type` | Вход | 2 | Тип завершённого кадра по tdl_tx_pkg. |
| `bf_filtered_event` | Вход | 1 | Подтверждённый BF-отказ от controller. |
| `fifo_full` | Вход | 1 | Уровень full входного FIFO. |
| `aging_done` | Вход | 1 | Сводный импульс от фасада policy. |
| `spi_addr_err_event` | Вход | 1 | Импульс ошибочной завершённой CSR-транзакции от wrapper. |
| `hit_rate_thresh` | Вход | 8 | Порог HIT_RATE_THRESH_REG. |
| `cnt_total_words` | Выход | 32 | Число принятых AXIS-слов. |
| `cnt_key_frames`, `cnt_raw_frames`, `cnt_sync_frames` | Выход | По 32 | Число завершённых кадров каждого типа. |
| `cnt_bf_filtered` | Выход | 32 | Число подтверждённых BF-отказов. |
| `fifo_full_event` | Выход | 1 | Переход fifo_full из 0 в 1. |
| `aging_event` | Выход | 1 | Завершение обслуживания. |
| `high_hit_rate` | Выход | 1 | Уровень превышения порога. |
| `spi_addr_err` | Выход | 1 | Событие ошибочного CSR-доступа. |

## Логика работы

### Счётчики

`axis_accept` увеличивает `cnt_total_words`. По `frame_done` обновляется счётчик типа `frame_done_type`. `bf_filtered_event` увеличивает `cnt_bf_filtered`. Разные события на одном фронте обновляют свои счётчики одновременно.

Асинхронный активный низкий reset обнуляет счётчики и историю full. Счётчики насыщаются на `32'hFFFFFFFF`. На максимуме последующие события сохраняют значение. После насыщения отношение счётчиков отражает ограниченную историю.

Зарезервированный тип `2'b11` пропускается при подсчёте кадров. Bypass учитывается как завершённый RAW.

### Источники прерываний

```text
fifo_full_event = rst_n && fifo_full && !fifo_full_previous
high_hit_rate = (cnt_total_words != 0)
             && (255 * cnt_key_frames > hit_rate_thresh * cnt_total_words)
```

Произведения вычисляются в 40 битах. Условие использует текущие зарегистрированные счётчики, новое событие влияет на него после их обновления. Равенство порогу и нулевой total дают high_hit_rate=0.

`high_hit_rate` — уровень установки бита `INT_STATUS_REG`, который сохраняется до очистки ПО. Пока порог превышен, аппаратная установка имеет приоритет над W1C. `fifo_full_event` выдаётся один раз за непрерывное пребывание FIFO в `full`. Повторное заполнение создаёт новое событие. `aging_event` и `spi_addr_err` передают однотактные события в домене `clk`. `rst_n=0` подавляет импульсные выходы. Уровень `high_hit_rate` становится нулём после сброса счётчиков.

### Чтение статистики через CSR

Принятых слов может быть больше завершённых кадров из-за очередей. BF-событие возникает на commit, счётчик RAW обновляется после передачи.

CSR-мост подаёт значения на `CNT_*.val.next`. При чтении младшего байта CSR использует текущее значение на `hwif_in`. На фронте этого чтения `tx_regs` фиксирует все 32 бита. Три старших байта берутся из этого снимка.
